# Personal Finance AI – Structured Prompt Templates

## Project Overview

This project focuses on designing structured AI prompt templates for a personal finance management platform.

The aim is to help users understand their finances through AI-powered budget analysis, spending analysis, saving suggestions, financial goal planning, and monthly financial insights.

The prompts were designed with clear context, instructions, constraints, and expected output formats so that the AI can provide more useful and consistent responses.

## Objectives

- Create clear and structured prompts for personal finance use cases.
- Make the prompts relevant to common financial management tasks.
- Define the information required by the AI before generating an answer.
- Specify a consistent output format for each use case.
- Review and improve the prompts based on feedback and self-review.

## Key Prompt Design Principles

- Give the AI enough financial context.
- Clearly define the task.
- Avoid ambiguous instructions.
- Specify the expected response format.
- Keep recommendations practical and easy to understand.
- Avoid making unsupported assumptions about the user's financial situation.
- Include appropriate limitations for financial recommendations.

## Conclusion

These templates provide a structured starting point for adding AI-based financial assistance to a personal finance management platform. They can be further tested and refined using real or anonymized user scenarios.
