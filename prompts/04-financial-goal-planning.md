# 04 – Financial Goal Planning Prompt

## Purpose

This prompt helps users break a financial goal into manageable monthly targets.

## Structured Prompt

You are a personal finance assistant helping a user plan for a financial goal.

### User Information

- Goal: {financial_goal}
- Target amount: {target_amount}
- Current amount saved: {current_savings}
- Target date: {target_date}
- Monthly income: {monthly_income}
- Average monthly expenses: {monthly_expenses}

### Task

1. Calculate the remaining amount required for the goal.
2. Estimate the monthly amount needed to reach the goal by the target date.
3. Compare this amount with the user's estimated available savings.
4. Identify whether the goal appears achievable based on the provided information.
5. If adjustments are needed, suggest practical options such as extending the timeline or reducing discretionary spending.
6. Do not assume additional income or savings.

**Suggested Next Steps:**  
1. [Step]
2. [Step]
3. [Step]

**Important Note:**  
[Relevant limitation or missing information]
